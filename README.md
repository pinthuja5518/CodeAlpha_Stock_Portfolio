PROJECT DETAILS 

Project Name: Stock Portfolio Tracker

Domain: Finance / Stock Market Management

Programming Language Used: Python

Internship Project Title: Stock Portfolio Tracker using Python

OBJECTIVE 

To create a simple program that calculates total investment based on stock names and quantities entered by the user.

DESCRIPTION 

This project allows users to enter stock names and quantities. The program uses a predefined dictionary of stock prices and calculates the total investment value.

FEATURES 

✓User input for stock names and quantity

✓Predefined stock price list

✓Calculates total investment

✓Option to save results in .txt or .csv file

CONCEPTS USED 

✓Dictionary

✓Input / Output

✓Basic arithmetic

✓File handling (optional)

CONCLUSION 

This project helps understand dictionaries and basic calculations in Python. It simulates real-world stock tracking.
